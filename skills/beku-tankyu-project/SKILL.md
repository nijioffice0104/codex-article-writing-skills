# ベクさん探求プロジェクト

## 目的

読者の悩みを代弁し、筆者のBefore/After、実績報告、ノウハウのロジックを通じて興味を高め、有料note、個別相談、講座、LINE、メルマガへ自然につながる教育用無料noteを書く。

特定ジャンル専用ではなく、note販売全般に使う。

## 入力

・コンセプト
・ターゲット
・ターゲットの悩み
・解決策、手段、ノウハウ
・有料コンテンツの内容
・セールスレター、販売ページ、訴求メモ
・筆者のBefore/After、体験談、実績
・第三者の成功事例
・近況報告や実績報告として扱いたいニュース

不足があっても止まらず、仮説で補完する。
ただし、入力にない実績、数字、体験談、第三者事例は捏造しない。

## 参照ナレッジ

教育用記事の8段階構成、タイトル型、ストーリー化、見出し作成、本文作成、CTA、NGパターンは [free-note-playbook.md](references/free-note-playbook.md) を読む。

## 手順

1. 入力を読み、ターゲットの悩み、理想の未来、属性を整理する。

2. 有料コンテンツの主なポイントと、セールスレターの訴求要素を抽出する。

3. 本文の流れに沿って、どの素材をどのパートで使うか割り振る。

4. 読者にとって魅力的な大見出しを作る。`悩みの代弁` `Before` `After` などの構成名をそのまま見出しにしない。

5. タイトル案を作る。基本形は `〇〇だった私が△△で●●できた方法`。

6. 各見出しに対して400〜1000文字程度の本文を書く。

7. 全体を3000〜5000文字以内に整える。

8. 最後に有料コンテンツへの誘導文を書く。価格は記載しない。

## 制約

・特定ジャンルに固定しない
・教育用無料noteの本文を書くことを主目的にする
・一般論だけで終わらせず、ストーリー、数字、具体例を使う
・過剰な誇大表現、収益保証、効果保証は禁止
・価格の記載は禁止
・読者の不安を煽りすぎない
・読者を否定しない。ネガティブな内容は自分を主語に、ポジティブな内容は読者を主語にする
・初心者でも理解できる表現にする
・実績、数字、体験談、第三者事例は入力にない限り捏造しない
・有料誘導は本文の流れから自然につなげる
