# Codex Article Writing Skills

記事作成に使うCodexスキルだけをまとめた公開リポジトリです。

## 収録スキル

| Skill | Purpose |
| --- | --- |
| `coconala-blog-full-draft` | ココナラ商品ページ確認、読者に刺さるコンセプト・タイトル・見出し設計、記事作成、画像生成、未公開下書き保存、再オープン検証まで行う一気通貫スキル |
| `beku-tankyu-project` | note販売や集客の前段になる教育用無料noteを、コンセプト・ターゲット・実績報告から作る文章設計スキル |

## 使い方

1. このリポジトリをZIPで取得する。
2. ZIPを展開する。
3. `skills` フォルダの中身を、自分のPCの `.codex/skills/` に入れる。
4. Codexを再起動する。
5. 下の呼び出し文を使う。

## 呼び出し文

```text
$coconala-blog-full-draft を使って、商品ページを確認し、読者に刺さるコンセプト・タイトル・見出しを設計してから、ブログを書き、サムネと本文画像2枚をChatGPTで作成し、ココナラに未公開下書きとして保存して、再オープン検証までお願いします。
```

```text
$beku-tankyu-project を使って、実績報告をもとに、読者に伝わる無料noteを書いてください。
```

## 方針

- 記事を書くスキルだけを置く。
- 実績、数字、レビュー、資格、保証、希少性は、入力または公開ページで確認できるものだけ使う。
- 足りない情報は捏造せず、読者の悩み・不安・次の一歩を補って文章化する。
- ベクさん探求プロジェクトの「相手に訴えかける文章設計」を、記事作成スキルへ加えて育てる。
