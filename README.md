# Codex Skills Backup

ローカルで使っているCodexスキルをまとめた公開リポジトリです。

## 収録スキル

| Skill | Purpose |
| --- | --- |
| `beku-tankyu-project` | note販売や集客の前段になる教育用無料noteを、コンセプト・ターゲット・実績報告から作る文章設計スキル |
| `coconala-blog-full-draft` | ココナラ商品ページ確認、読者に刺さるコンセプト・タイトル・見出し設計、記事作成、画像生成、未公開下書き保存、再オープン検証まで行う一気通貫スキル |
| `coconala-contents-market-draft` | 既存ココナラサービスページから、コンテンツマーケット用PDF/ファイル販売の未公開下書きを作るスキル |
| `coconala-blog-image-generator` | ワンクリック卓から画像生成依頼文を抽出し、ChatGPT側でサムネ・記事画像を生成して確認するスキル |
| `coconala-blog-oneclick` | ココナラブログ記事を作成し、画像生成と下書き保存まで進めるワンクリック系スキル |
| `coconala-blog-upload-draft` | ココナラブログ本文・画像を作り、未公開下書きとして保存して再確認するアップロード用スキル |
| `relife-art-carousel-chatgpt` | Relife Art系のInstagram/TikTokカルーセル画像をChatGPTで生成し、見た目を検証するスキル |
| `ut-analysis` | UT結果を分析し、観察と解釈を分けた分析レポートを作るスキル |
| `ut-learning` | ユーザーテスト、ユーザビリティ、UX/UIを学ぶためのラーニング用スキル |
| `ut-moderator` | ライブUTセッションを進行し、観察結果を記録するモデレーター用スキル |
| `ut-scenario` | UTの参加者向け・進行者向けシナリオを作成または更新するスキル |
| `ut-setup` | プロジェクトにUTワークフローをセットアップするスキル |
| `ut-shared` | UT系スキル共通のルール、テンプレート、参照ファイル |

`*.backup-20260727T035600Z` の名前が付いたフォルダは、同名UTスキルのバックアップ版です。

## 使い方

1. このリポジトリをZIPで取得する。
2. ZIPを展開する。
3. `skills` フォルダの中身を、自分のPCの `.codex/skills/` に入れる。
4. Codexを再起動する。
5. 使いたいスキル名を `$skill-name` の形で呼び出す。

## 方針

- `.system` はCodex本体側のシステムスキルなので、このバックアップには含めない。
- 実績、数字、レビュー、資格、保証、希少性は、入力または公開ページで確認できるものだけ使う。
- 足りない情報は捏造せず、読者の悩み・不安・次の一歩を補って文章化する。
- 画像生成系は、指定されたChatGPT側の生成ワークフローを優先する。
